# Samiksha Sapkota — Portfolio Website

Personal portfolio website for **Samiksha Sapkota**, a Civil Engineer from Kathmandu, Nepal, specialising in structural design, seismic analysis, and architectural drafting.

🌐 **Live site:** [samiksha-sapkota.com.np](https://samiksha-sapkota.com.np)

---

## Overview

A fully hand-coded, single-page portfolio built with vanilla HTML, CSS, and JavaScript — no frameworks, no build tools. Designed to be fast, accessible, and visually distinctive.

### Sections

- **Hero** — Introduction with animated typewriter role titles and a photo card
- **About** — Background, education, and personal story
- **Experience** — Work and internship timeline
- **Skills** — Interactive skill display with both bar and radar chart views
- **Projects** — Featured engineering projects with tags
- **Resume** — CV download (PDF)
- **Contact** — Contact form with email delivery via EmailJS

---

## Tech Stack

| Layer | Technology |
|---|---|
| Markup | HTML5 (semantic) |
| Styling | CSS3 (custom properties, grid, animations) |
| Scripting | Vanilla JavaScript (ES6+) |

## Features

- **Animated preloader** with name reveal and progress bar
- **Particle canvas** background effect
- **Parallax blobs** and floating decorative elements
- **Typewriter** effect cycling through role titles
- **Tilt card** effect on the profile photo
- **Skills tabs** — switch between progress bars and a radar chart
- **Scroll-triggered animations** using IntersectionObserver
- **Scroll progress bar** at the top of the page
- **Custom cursor** on desktop
- **Light / dark mode** toggle with localStorage persistence
- **Contact form** with inline validation and EmailJS integration
- **Fully responsive** layout for mobile, tablet, and desktop
- **SEO-ready** — meta tags, Open Graph, Twitter Card, and JSON-LD structured data
